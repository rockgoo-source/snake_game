# 스네이크 게임

바닐라 JavaScript와 Canvas 2D로 만든 클래식 스네이크 게임입니다. 외부 라이브러리 없이 파일을 열기만 하면 바로 플레이할 수 있습니다.

## 실행 방법
1. 저장소를 내려받습니다.
2. `index.html`을 데스크톱 크롬으로 엽니다. (더블클릭하면 됩니다)

설치, 빌드, 로컬 서버가 필요 없습니다.

## 조작법
- **Play** → 난이도(Easy / Normal / Hard) 선택
- 뱀은 정지해 있다가 첫 방향 입력으로 출발합니다 (시작 시 왼쪽 입력은 무시)
- 방향키 또는 `W` `A` `S` `D`: 방향 전환
- 현재 진행 방향의 반대 방향 입력은 무시됩니다
- 게임오버 화면의 **Retry**(같은 난이도로 재시작) / **Exit**(시작 화면으로)

## 게임 규칙
- 먹이를 먹으면 길이 +1, 점수가 오르고 새 먹이가 빈 칸에 생성됩니다
- 먹이 5개를 먹을 때마다 속도가 한 단계 빨라집니다
- 벽이나 자기 몸통에 닿으면 게임오버입니다 (같은 틱에 비워지는 꼬리 칸은 통과)
- 보드가 가득 차면 CLEAR
- 화면 위쪽에 최고 점수, 현재 점수, 경과시간이 표시됩니다
- 최고 점수는 난이도별로 저장되어 새로고침 후에도 유지됩니다

### 난이도
| 항목 | Easy | Normal | Hard |
|---|---|---|---|
| 보드 | 6x6 | 10x10 | 16x16 |
| 시작 틱 / 단계당 감소 / 하한 | 250 / 5 / 110ms | 150 / 10 / 60ms | 120 / 10 / 50ms |
| 먹이 1개 점수 | 10 | 15 | 20 |
| 보드에 유지되는 먹이 | 3 | 3 | 1 |
| 시간 먹이 | 없음 | 20초마다, 최대 2개 | 10초마다, 개수 제한 없음 |

### 시간 먹이 (Normal / Hard)
- 노란색 1회용 먹이입니다. 먹으면 길이 +1, 점수는 일반 먹이와 같습니다
- 보드의 빈 칸이 부족하면 생성되지 않습니다
- Hard에서는 먹으면 틱 간격이 10ms 늘어 느려집니다 (시작 속도보다 느려지지는 않음). 이 먹이는 속도 증가 개수에 포함되지 않습니다

## 현재 상태
- [x] MVP: 이동, 먹이, 충돌, 점수·시간 표시, Play / Retry / Exit
- [x] 2차: 최고 점수 localStorage 저장, 속도 증가
- [x] 3차: 난이도 선택, 난이도별 먹이 개수, 시간 먹이

## 기술 스택
- HTML + CSS + JavaScript (ES6+) 3파일
- Canvas 2D (칸 24px, 난이도별 144~384px, devicePixelRatio 대응)
- 외부 라이브러리, 웹폰트, 빌드 도구 없음
