# 스네이크 게임

바닐라 JavaScript와 Canvas 2D로 만든 클래식 스네이크 게임입니다. 외부 라이브러리 없이 파일을 열기만 하면 바로 플레이할 수 있습니다.

![스크린샷](docs/screenshot.png)

## 실행 방법
1. 저장소를 내려받습니다.
2. `index.html`을 데스크톱 크롬으로 엽니다. (더블클릭하면 됩니다)

설치, 빌드, 로컬 서버가 필요 없습니다.

## 조작법
- 방향키 또는 `W` `A` `S` `D`: 방향 전환
- 현재 진행 방향의 반대 방향 입력은 무시됩니다
- 시작 화면의 **Play**, 게임오버 화면의 **Retry**(즉시 재시작) / **Exit**(시작 화면으로)

## 게임 규칙
- 20 x 20 보드에서 뱀이 150ms마다 한 칸씩 움직입니다
- 먹이를 먹으면 길이 +1, 점수 +10, 새 먹이가 빈 칸에 생성됩니다
- 벽이나 자기 몸통에 닿으면 게임오버입니다 (같은 틱에 비워지는 꼬리 칸은 통과)
- 보드가 가득 차면 CLEAR
- 화면 위쪽에 최고 점수, 현재 점수, 경과시간이 표시됩니다

## 현재 상태
- [x] MVP: 이동, 먹이, 충돌, 점수·시간 표시, Play / Retry / Exit
- [ ] 2차: 최고 점수 localStorage 저장, 점수에 따른 속도 증가

## 기술 스택
- HTML + CSS + JavaScript (ES6+) 3파일
- Canvas 2D (칸 24px, 480x480, devicePixelRatio 대응)
- 외부 라이브러리, 웹폰트, 빌드 도구 없음

## 프로젝트 구조
```
index.html   화면 구조 (HUD, 캔버스, 오버레이)
style.css    스타일
game.js      게임 로직과 렌더링
PRD.md       요구사항 문서
CLAUDE.md    프로젝트 작업 규칙
```

## 개발 메모
바이브 코딩 학습과 포트폴리오를 목적으로 만들었습니다. 요구사항은 `PRD.md`에, 작업 규칙은 `CLAUDE.md`에 정의하고 그에 맞춰 기능을 하나씩 구현했습니다.
